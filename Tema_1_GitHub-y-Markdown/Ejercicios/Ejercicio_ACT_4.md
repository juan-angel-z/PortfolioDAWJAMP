# Actividad 4: Seguridad y accesibilidad en el control de versiones

Esta actividad reúne los archivos básicos para mejorar la seguridad y la organización de un repositorio GitHub.

## Archivos incluidos

- [`.gitignore`](./Ejercicio_ACT_4/.gitignore): evita que se añadan al repositorio archivos temporales, dependencias locales y ficheros que pueden contener información sensible.
- [`SECURITY.md`](./Ejercicio_ACT_4/SECURITY.md): recoge recomendaciones para comunicar vulnerabilidades, proteger el repositorio, gestionar permisos y recuperar cambios.

## Buenas prácticas

Es importante no publicar contraseñas, claves privadas o tokens. También conviene asignar a cada colaborador únicamente los permisos que necesita y revisar los cambios antes de incorporarlos a la rama principal.

**Nota sobre las evidencias:** no se han añadido capturas de una prueba real de permisos con colaboradores. La memoria explica cómo debe realizarse esa comprobación, pero no presenta como realizada una prueba de la que no se dispone de evidencia.
