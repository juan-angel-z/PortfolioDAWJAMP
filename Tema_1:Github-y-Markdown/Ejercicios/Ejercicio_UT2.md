## Introducción

GitHub es una plataforma basada en la nube que permite almacenar, gestionar y compartir proyectos mediante repositorios. Está especialmente relacionada con el desarrollo de software, aunque también puede utilizarse para organizar documentos, trabajos y otros tipos de archivos.

GitHub utiliza Git, un sistema de control de versiones que permite registrar los cambios realizados en un proyecto a lo largo del tiempo. De esta manera, es posible consultar versiones anteriores de los archivos y trabajar de forma organizada, tanto individualmente como en equipo.


## 1. Crear una cuenta de GitHub
### Pasos
1. Acceder a la página oficial de [GitHub](https://github.com/).
2. Seleccionar la opción __Sign up__.
3. Introducir una dirección de correo electrónico.
4. Crear una contraseña y elegir un nombre de usuario.
5. Completar el proceso de verificación.
6. Seguir las instrucciones que aparecen en pantalla para terminar de configurar la cuenta.


## 2. Crear un repositorio
### Pasos
1. Pulsar el botón __New__ para crear un nuevo repositorio.
2. Escribir el nombre del repositorio.
3. Añadir una descripción si se considera necesario.
4. Elegir si el repositorio será __público__ o __privado__.
5. Se puede seleccionar la opción de crear el repositorio con un archivo __README.md__.
6. Pulsar __Create repository__.


## 3. Crear una carpeta

GitHub no permite crear una carpeta vacía, por lo que es necesario crear un archivo dentro de ella.

### Pasos
1. Entrar en el repositorio.
2. Pulsar __Add file__.
3. Seleccionar __Create new file__.
4. Escribir el nombre de la carpeta seguido de `/` y del nombre del archivo.  
Por ejemplo:

```
dario/DIARIO_UT1.md
```

5. Escribir el contenido del archivo.
6. Pulsar Commit changes.


## 4. Subir un archivo al repositorio
### Pasos
1. Entrar en el repositorio.
2. Pulsar __Add file__.
3. Seleccionar __Upload files__.
4. Arrastrar los archivos a la página o seleccionarlos desde el ordenador.
5. Escribir un mensaje que describa el cambio realizado.
6. Pulsar __Commit changes__.


## 5. Editar un archivo
### Pasos
1. Abrir el repositorio.
2. Seleccionar el archivo que se quiere modificar.
3. Pulsar el icono del lápiz para editarlo.
4. Realizar los cambios necesarios.
5. Escribir un mensaje que indique qué se ha modificado.
6. Pulsar __Commit changes__.


## 6. Eliminar un archivo
### Pasos
1. Abrir el archivo que se desea eliminar.
2. Pulsar el menú de opciones.
3. Seleccionar __Delete file__.
4. Comprobar que se trata del archivo correcto.
5. Escribir el mensaje del cambio.
6. Pulsar __Commit changes__.


## 7. Cambiar el nombre de un archivo
### Pasos
1. Abrir el archivo.
2. Pulsar el icono del lápiz para editarlo.
3. Modificar el nombre del archivo en la parte superior.
4. Mantener la extensión correspondiente, por ejemplo .md.
5. Pulsar __Commit changes__.

Por ejemplo, podemos cambiar:
```
documento.md
```
por:
```
GitHub.md
```


## 8. Crear enlaces entre archivos del repositorio
Una función especialmente útil para organizar un portfolio es enlazar unos archivos con otros.

Por ejemplo, si tenemos un archivo llamado DIARIO_UT1.md, podemos crear un enlace desde otro archivo utilizando:

```
[Diario de la UT1](./diario/DIARIO_UT1.md)
```
De esta forma, al pulsar sobre el texto del enlace, GitHub nos llevará directamente al archivo indicado.

Esto permite crear índices y organizar un portfolio de manera sencilla.


## 9. Realizar un commit
Un commit es un registro de los cambios realizados en un repositorio. Los commits permiten saber qué modificaciones se han realizado y cuándo.

Cuando modificamos o creamos un archivo desde GitHub, normalmente debemos escribir un mensaje que describa el cambio.

Por ejemplo:
```
Añadido el diario de la UT1
```
Después se selecciona __Commit changes__.


## 10. Consultar el historial de cambios
### Pasos
1. Entrar en el repositorio.
2. Acceder a la sección __Commits__.
3. Seleccionar el commit que se quiera consultar.
4. Revisar los archivos que fueron modificados.

## 11. Compartir un repositorio
### Pasos
1. Entrar en el repositorio.
2. Copiar la dirección que aparece en el navegador.
3. Compartir esa dirección con la persona correspondiente.


## 12. README.md
El archivo `README.md` suele utilizarse como presentación o introducción de un repositorio.

En él se puede explicar de qué trata el proyecto, incluir información importante, instrucciones de uso, enlaces y otros datos relevantes.


## Conclusiones

Durante la realización de este documento he podido conocer algunas de las funciones principales de GitHub y comprender mejor cómo se organiza un repositorio.

GitHub permite almacenar proyectos, organizar archivos y carpetas, realizar modificaciones y mantener un historial de los cambios realizados. Además, mediante Markdown es posible crear documentos con una estructura clara y añadir enlaces que facilitan la navegación entre diferentes archivos.

Considero que aprender a utilizar estas herramientas puede ser útil para organizar trabajos y proyectos, especialmente cuando se necesita mantener un registro de las diferentes versiones y compartir el contenido con otras personas.
